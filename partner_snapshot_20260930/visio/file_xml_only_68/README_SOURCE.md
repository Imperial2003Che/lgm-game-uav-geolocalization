# Offline native Visio file authoring

The selected author is `build_offline_vsdx_v2.py`, with the fixed
`INPUT_MANIFEST_v2.json`. The original builder, its initial line-cap draft,
the original input manifest, and the complete v2 delta remain preserved.
No VSDX has yet been generated by publication of this source note.

The inputs are 68 already-adopted SVG figures from six families: two
bidirectional transfer figures, 22 single-seed robustness figures, and 11
figures each for visual-margin strata, selective risk, margin-score
reliability, and paired selective success. The 177 small input bindings
include the six respective figure-adoption roots, the 68 actual SVG files,
original family caption/readme/index/provenance files, and source CSV/JSON.
No checkpoint, image, cache, NPZ, old delivery ZIP or scientific calculation
is read or performed. The native author only translates displayed objects.

Each SVG rect, circle, line and text object becomes one flat native Shape
with explicit ShapeSheet cells. Rectangle/line geometry uses MoveTo/LineTo;
circles use native Ellipse rows. Text uses native Text, Character and
Paragraph rows. No grouped proxy, embedded SVG, raster, foreign image,
OLE, Excel, master, thumbnail, stale window or copied application metadata
is used. Each file is a fresh nine-part OPC/XML package. The original
181.9 mm width, heights, colors, visible text, Arial font sizes (at least
8 pt), source geometry/order, data and all negative results are retained.
Unsupported tags, attributes, styles, transforms, effects, text children,
nonuniform viewBox scaling and ambiguous fonts/colors fail closed.

The installed Arial TTF files are bound by full size/SHA and read with
stdlib cmap/hmtx/hhea/legacy-kern parsing. Text is anchored using native
paragraph alignment and explicit zero margins. Its initial box includes
0.2 em advance reserve and hhea ascender/descender baseline construction.
GPOS/shaping, native font kerning, baseline placement and wrapping have
not been tested in the Visio application. SVG lines have butt caps;
Microsoft documents native LineCap 1 as Square, so native cap appearance
parity is also unvalidated. The author does not claim render equivalence.

Each native PageSheet User.Notes contains the complete, unchanged family
CAPTIONS.md text and exact source/adoption/data descriptors. Original SVG,
CSV/JSON, captions, index and README bytes are also copied unchanged to
sidecar sources. These are the adopted captions, including all original
units, denominators, scope restrictions and inherited evidence-chain gaps;
this conversion is not new scientific evidence.

The first authorized generation is `--mode sample_t3` (two transfer files)
in a new `sample_t3` directory. The later `--mode full68` uses a separate
new `output68` directory only after review of the two saved sample files.
Any existing output directory, including an empty or partial attempt,
refuses replay. Failures retain partial artifacts and diagnostic evidence.
Author checks cover actual saved ZIP CRC/member bytes and native object
counts; independent input/XML checks and saved-XML CPU previews are separate
reviewer responsibilities.

Actual files, once generated, are an intermediate native XML deliverable.
`visio_open_validated=false`, `visio_roundtrip_pending=true`, and native
application rendering/GUI editing/final visual adoption remain pending.
A CPU preview of saved XML is not a Visio application render. No COM,
Office, guarded candidate, native scientific probe or scientific library
is invoked. The preexisting user Visio process and all scientific queue,
boot, resource, shared-lock, release and sequence gates remain untouched.
